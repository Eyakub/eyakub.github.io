Off this path: port 80 gets 301 to https. 308 keeps the method. A refused app is 502. A timeout is 504.

dig +trace example.com    curl -v https://example.com

A cache miss. The recursive resolver looks up example.com. dig +trace follows the referrals.

The A record is 203.0.113.10, a documentation address. Caches reuse it until the TTL ends.

TCP port 443: client SYN, server SYN-ACK, client ACK. HTTP/3 uses QUIC instead.

HTTPS uses TLS 1.3: ClientHello, then the certificate. The load balancer ends TLS.

Over the encrypted connection the browser sends GET /api/items with a Host header.

The load balancer picks a backend, round-robin or least-connections, and can add X-Forwarded-For.

Nginx, the reverse proxy, forwards with proxy_pass. Static files it serves from disk itself.

The app server takes a pooled connection and runs SELECT * FROM items.

The rows come back. The app writes 200 OK and a JSON response body.

The 200 OK response returns through Nginx and the load balancer to the browser.

The browser renders the page. DevTools Timing splits DNS, connection, TTFB, and download.
