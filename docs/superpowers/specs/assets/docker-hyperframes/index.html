Without a volume, docker rm deletes the writes.

A Dockerfile lists instructions. FROM picks the base, COPY adds files, RUN runs a command, and CMD is the default. .dockerignore stays out of the context.

docker build -t myapp:1.0 . freezes the image. Each instruction adds a read-only layer. An image does not change once built.

Unchanged layers stay cached. A changed layer rebuilds every layer after it. Put pip install before COPY . . so a code edit skips the install.

docker push uploads the image. docker tag can add the registry host. Layers the registry already holds are not sent again.

docker pull downloads the image. With no tag it uses :latest. Layers already on the machine are not fetched again.

docker run -p 8000:8000 -v data:/data myapp adds a writable layer and runs CMD. -p publishes port 8000. The kernel is the host’s.

The named volume data is mounted at /data. Writes go there, not to the writable layer. Docker creates the volume if it is missing.

docker rm deletes the container and its writable layer. The named volume stays. docker rm -v removes only anonymous volumes.

A new container starts from the same image with a fresh writable layer. Mounting data brings the old files back.
