git pull does not merge the pull request. Do not force-push main.

git switch -c feat/x starts the head from main. A fork is a separate repository.

git push -u origin feat/x sets upstream. main does not move.

A pull request asks to merge feat/x into main. main stays put.

pull_request reports a status. A protected branch can require success, skipped, or neutral.

A review can comment, approve, or request changes.

A merge commit does not fast-forward. Squash is one commit. Rebase writes new commits.

git switch main and git pull. Deleting the head branch is optional.
