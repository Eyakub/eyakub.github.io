A refused upstream is 502. A timeout is 504.

GET /static/logo.png arrives on HTTPS port 443. Nginx matches listen, server_name, then location /static/.

TLS ends here: listen 443 ssl, with ssl_certificate and ssl_certificate_key. The upstream stays plain HTTP.

root /var/www turns /static/logo.png into /var/www/static/logo.png. expires 30d can cache it.

Nginx answers 200 OK from disk. Static files skip the app servers.

GET /api/items misses /static/. location / does proxy_pass http://backend, an upstream pool.

Round-robin picks app server 1, weight=1. Host is rewritten. Connection: close. proxy_set_header can override both.

App server 1 returns 200 and JSON. proxy_buffering on, so a slow browser does not hold the app.

The next GET /api/items goes to app server 2. ip_hash would keep one client on one server.

App server 2 answers the same way. Add a server line, then nginx -t and nginx -s reload.
