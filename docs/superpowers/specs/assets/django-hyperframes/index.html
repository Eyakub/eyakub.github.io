Off this path: A missing CSRF token is 403 before the view runs. No urlpatterns match is 404. An uncaught view exception is 500.

The browser sends POST /orders/ with a form body. Gunicorn calls WSGIHandler, which builds a WSGIRequest: an HttpRequest with method, POST, and META.

Middleware runs top-down through MIDDLEWARE. SessionMiddleware sets request.session. AuthenticationMiddleware adds request.user, loaded only on first use. CsrfViewMiddleware only reads its secret for now.

From ROOT_URLCONF, Django tries each urlpatterns entry in order against path_info and stops at the first match. That match gives a view plus any captured arguments.

Django then calls every process_view, top-down, just before the view. CsrfViewMiddleware runs after URL resolution, so it can see csrf_exempt. A POST needs a token matching the secret.

No process_view returned a response, so Django calls the view with the HttpRequest and the URL arguments. Dish.objects.filter only builds a lazy QuerySet. No SQL has run yet.

Evaluating the QuerySet runs the SELECT. Iterating, list, len, bool, and slicing with a step all evaluate it. Here the view does it, so the query runs now.

The database returns the matching rows. The QuerySet caches them, so reusing the same variable costs no new query. A fresh Dish.objects.all queries again.

render combines the template with the context and returns an HttpResponse. Variables are HTML-escaped by default. An unevaluated QuerySet in the context would query inside a for loop here.

The rendered page returns as an HttpResponse with status 200. A TemplateResponse renders later, after process_template_response, and only if the response has a render method.

The response passes back in reverse MIDDLEWARE order. CsrfViewMiddleware sets the CSRF cookie if one is needed. SessionMiddleware saves the session if it changed and sets its cookie.

WSGIHandler calls start_response with the status line and headers, then returns the body to the WSGI server, which sends it to the browser. Under ASGI, ASGIHandler does this job.
