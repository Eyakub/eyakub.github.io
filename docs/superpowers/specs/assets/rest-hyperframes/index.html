Off this path: 401 means no credentials and sends WWW-Authenticate. 403 means understood and refused.

curl -i http://localhost:8000/parcels/42

GET /parcels/42 reads one resource. It is safe and idempotent, and it sends no body.

Only the server maps that URL to stored state. The interface is the method plus the resource.

A found representation comes back as 200. A missing resource is 404.

POST lets the server name the new resource. A repeat is not idempotent.

201 means a resource was created. Location names it, and a later GET should see it.

PUT replaces the resource and is idempotent. PATCH applies every change or none.

DELETE removes the URL’s current function. A second call leaves the same state.
